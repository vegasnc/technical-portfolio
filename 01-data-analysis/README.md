# Data Analysis

This project uses a generated dataset to demonstrate summary statistics, charts, and linear regression.

## Files

- `synthetic_practice_data.csv` - 60 generated records
- `analysis.do` - Stata script
- `overall_summary.csv` - summary statistics for the numeric variables
- `group_summary.csv` - summary statistics by group
- `hours_vs_outcome.png` - scatter plot with fitted line
- `mean_outcome_by_group.png` - average outcome by group

## Results

The dataset contains a positive relationship between hours and outcome score. Since the values were generated for practice, the result should not be treated as evidence about a real-world population.

Open the CSV in LibreOffice Calc to explore the data and create your own tables or charts. In Stata, run `analysis.do` to reproduce the descriptive statistics and regression.
