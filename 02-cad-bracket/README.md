# Parametric Mounting Bracket

This project contains a FreeCAD macro for a simple L-shaped mounting bracket.

## Model dimensions

- Base plate: 80 × 40 mm
- Plate thickness: 6 mm
- Upright height: 50 mm
- Two nominal 8 mm mounting holes

## Files

- `create_bracket.FCMacro` - creates the model in FreeCAD
- `parametric_mounting_bracket.FCStd` - native model, generated when the macro runs
- `parametric_mounting_bracket.step` - STEP export, if export succeeds

The model is a starting point for CAD practice. Check the geometry, hole placement, and plate intersection in FreeCAD before using or sharing it as a finished design.
