# Portfolio Projects

This repository contains three practice projects covering data analysis, parametric CAD, and structural analysis.

## Projects

- **Data analysis:** Explore a synthetic dataset, summarize the results, and examine the relationship between two variables.
- **CAD bracket:** A FreeCAD macro for creating a simple mounting bracket.
- **Cantilever beam:** A hand-calculation benchmark for checking displacement and bending stress in a simplified beam model.

The data-analysis example uses generated data. The CAD model should be checked in FreeCAD, and the cantilever calculations are an analytical benchmark rather than results from a finite element solver.
